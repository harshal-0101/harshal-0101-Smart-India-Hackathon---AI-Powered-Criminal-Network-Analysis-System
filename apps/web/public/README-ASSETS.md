# Video & Media Assets Directory

To supply custom live drone/CCTV surveillance footage for the homepage:
1. Save your MP4 video at: `apps/web/public/hero-demo.mp4`
2. Save your WebM video at: `apps/web/public/hero-demo.webm` (optional)
3. Save your poster image at: `apps/web/public/hero-poster.jpg`

The application includes an SVG fallback (`hero-poster.svg`) and an interactive procedural OpenCV HUD simulation overlay that displays live bounding boxes, tracking vectors, and detection telemetry even before a video file is supplied.
